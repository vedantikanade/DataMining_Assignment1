## How It Was Built

### 1. Initial Scaffold (`gpt-engineer`)
I started by running `gpt-engineer` in the terminal to generate the initial HTML, CSS, and JavaScript files. Since standard OpenAI API credits were exhausted, I configured `gpt-engineer` to run using a free Groq API key (`OPENAI_API_BASE` pointing to Groq) to generate the baseline project.

### 2. AI Demonstrations in Editor
Once the base files were created, I used Cursor's built-in AI tools to build out the application:

* **UI Refactoring (`Cmd + I`):** The initial UI generated by `gpt-engineer` was very plain. I tagged `index.html` and `style.css` in Composer and asked the AI to redesign it into a modern dark-mode dashboard using Tailwind CSS.
* **Inline Code Generation (`Tab`):** In `script.js`, I added a comment asking for a CSV export feature (`// Function to export expenses array to CSV`), and used inline Tab completion to generate the file download logic.
* **Unit Testing (`Cmd + L`):** Highlighted the `ExpenseTracker` class, opened AI Chat, and generated Jest unit tests. I saved these into `script.test.js`.
* **Feature Extension (`Cmd + I`):** Used Composer to add a Budget Limit Warning system across `index.html` and `script.js` that flags spending when total expenses exceed a user-defined cap.
